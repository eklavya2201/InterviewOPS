Interviewer Model Benchmark

Each model conducts the same mock interview against a Claude-simulated fresher candidate; the transcripts are then scored by the same LLM-as-judge meta-eval that audits the live app. Higher is better on every dimension (0–10).

How it works

1. Same candidate for every model. A Claude-played "fresher AI engineer" persona answers every interviewer, so differences come from the interviewer, not the candidate. 2. Blind judging. The judge sees only the transcript — it doesn't know which model conducted the interview. 3. Same rubric as production. The meta-eval dimensions (follow-up quality, relevance, difficulty calibration, factual accuracy) are the exact scores shown on every live report's "Interviewer Self-Audit" panel.
